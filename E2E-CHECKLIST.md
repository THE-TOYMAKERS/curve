# Curve interaction validation

This checklist retains the predecessor Aperture 0.2.0/0.2.1 observations recorded on October 23, 2026. Those observations are historical evidence, not newly completed Curve 0.3.0 passes. Run the relevant cases again after the Curve sources are frozen; record the actual version and build with each new result. The naming, icon, first-launch session migration, and changed bundle identity also require explicit release checks.

This is the live test matrix for the typography, full-screen layout, motion, and drag pass. **Pending** means the interaction has not yet been verified in the current build. A keyboard routing assertion is not an end-to-end pass. Existing core, router, engine, and store checks remain separate automated evidence; run them again after sources are frozen.

Use the isolated **Curve QA** app and localhost fixture described in [Checks/QA-Fixture/README.md](Checks/QA-Fixture/README.md). This reproducible source fixture has no personal data or generated profile/app; runtime files are generated under `.build/qa-fixture`. Reset only after quitting the QA app. Record the observed outcome, build/version, and any screenshot or accessibility-tree evidence for each completed live case.

The historical live evidence below was collected through native UI automation. Earlier keyboard/menu/pointer outcomes are scoped to the 0.2.0 QA builds unless a row explicitly records the 0.2.1 retest.
