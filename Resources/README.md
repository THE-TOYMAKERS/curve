# Curve artwork

`Curve-Ribbon-C.png` is the approved Ribbon C logo, selected on October 26, 2026, from a built-in imagegen exploration for Curve. This original 1254 × 1254 PNG is the canonical artwork; its transparency and colors are preserved when packaging the app icon.

`AppIcon-1024.png` and `AppIcon.icns` are generated from this source by `../Scripts/make-icon.sh`, using macOS `sips` and `iconutil`. The ICNS includes 16, 32, 128, 256, and 512-point sizes with Retina variants up to 1024 pixels. No image-generation service or third-party package is needed to rebuild the icon.

The direction uses an open rounded C with overlapping coral, cobalt, violet, and salmon ribbons. It was created as a distinct Curve mark from a reference's playful rounded strokes and saturated palette.
